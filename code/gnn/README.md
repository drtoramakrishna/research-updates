# Graph Neural Networks (GNN) - Complete Learning Guide

A comprehensive resource for understanding Graph Neural Networks theory, implementation, and real-world applications.

## 📚 Curriculum Structure

### Module 1: Fundamentals
- **01_graph_basics.ipynb** - Graph theory fundamentals and representations
- **02_graph_signal_processing.ipynb** - Signal processing on graphs

### Module 2: GNN Architectures
- **03_message_passing_framework.ipynb** - Message passing neural networks
- **04_graph_convolutional_networks.ipynb** - GCN implementation and theory
- **05_graph_attention_networks.ipynb** - GAT architecture and mechanics
- **06_graph_isomorphism_networks.ipynb** - GIN and expressive power

### Module 3: Advanced Topics
- **07_heterogeneous_gnns.ipynb** - Handling heterogeneous graphs
- **08_temporal_graphs.ipynb** - Temporal and dynamic graphs
- **09_graph_generation.ipynb** - Generative models for graphs

### Module 4: Real-World Applications
- **10_node_classification.ipynb** - Node-level prediction tasks
- **11_link_prediction.ipynb** - Graph edge prediction
- **12_graph_classification.ipynb** - Graph-level classification
- **13_molecular_property_prediction.ipynb** - Chemistry applications

### Module 5: Best Practices
- **14_training_strategies.ipynb** - Optimization and training
- **15_evaluation_metrics.ipynb** - Performance measurement
- **16_benchmark_datasets.ipynb** - Common datasets and baselines
